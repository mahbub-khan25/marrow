# Security

Marrow keeps notes on your own computer, and locked notes are encrypted.
If you find a way around that (reading a locked note without its password,
leaking note text into logs, caches or backups, or running code from a note
or plugin without permission), please report it privately.

**How to report:** use [Report a vulnerability](https://github.com/mahbub-khan25/marrow/security/advisories/new)
on GitHub. Please don't open a public issue. Include the steps to reproduce
and the Marrow version (Settings → About).

You'll get a reply within a week. Fixes go into the next release, and you'll
be credited unless you'd rather not be.

Only the latest release gets security fixes.
