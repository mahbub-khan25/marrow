Chapter 1

Getting started

A vault is just a folder. Every note in it is a .md file you can open in any text editor, back up, sync with OneDrive or Dropbox, or move to another app. Marrow adds a hidden .marrow folder for its own things (history, trash, plugins) and never locks your notes into a format.

  1. Start Marrow. The first time, it asks for a folder. Pick an empty one to start fresh, or a copy of an existing Obsidian vault.
  2. The empty vault shows three buttons: New note (Ctrl+N), Today's note (Ctrl+D) and Search (Ctrl+K).
  3. Click the title to name the note, then start typing. Marrow saves two seconds after you stop.
Coming from Notion, Evernote, OneNote or Word? Press Ctrl+K and choose Import notes…. Pages, links, tags, properties and pictures come across into a new folder; the files you pick are only read.

Chapter 3

Writing notes

Notes open in Preview, which reads like a finished page. Double-click a paragraph, or press Ctrl+E, to edit it in Source. Source hides Markdown marks except on the line you're typing, so it stays tidy, and the toolbar above it formats text if you'd rather not type ** and #.

What a note can hold

  • Callouts like > [!tip] Try this, coloured by type. Click the icon in Preview to change the type.
  • Maths with $g = r \times t$ inline or $$ … $$ on its own lines.
  • Tables you edit by clicking a cell. Tab moves on and adds a row at the end; right-click for sorting and columns.
  • Diagrams in Mermaid: flowcharts, sequences, mind maps, timelines, Gantt, pie and more.
  • Images and files: paste a screenshot or drag files in. They're saved in the vault's attachments folder.
  • Footnotes, toggles, columns, buttons, code coloured by language, and synced blocks that edit the original wherever they're embedded.
History is automatic. Right-click a note → Version history… to see earlier copies and restore one. Copies are kept every few minutes while you edit, thinning out to daily over a year.
Chapter 4

Links, tags and the graph

Type [[ and pick a note to link it. Linking to a note that doesn't exist yet is fine: click the link and Marrow creates it. Rename a note and every link to it updates. Add #tags anywhere in the text or in the note's properties.

Rest the pointer on a link in Preview to read that note in a small card without leaving the page. Star the notes you use most (right-click → Star) to keep them at the top of the tree.

Chapter 6

Daily notes and tasks

Press Ctrl+D (or the calendar in the rail) for today's note. It lives in the Daily folder, named by date, with Log and Tasks sections. The arrows beside the date step to the day before or after.

  • Give a task a date with 📅 2026-10-20, due: 2026-10-20 or a [[2026-10-20]] link.
  • Quick capture: press Ctrl+Alt+N in any app while Marrow is open, even minimised, to jot a line or a to-do into today's note.
Chapter 7

Databases

A database shows the notes in a folder as a table, board, calendar or gallery, using their properties as columns. Type /database in a note, or right-click a folder → View as database. Every row is a real note, and every cell is a property in it.

The block behind it is plain text, so you can fine-tune it in Source:

```database
from: Garden
view: board
columns: [status, due]
group: status
sort: due desc
filter: status != Done
```

Relations and rollups. A property holding [[links]] is a relation, and project.owner reads owner from the linked note. count(), sum(), avg() and percent() roll values up, for example Done = percent(backlinks.done).

Chapter 8

Canvas

A canvas is an endless board for laying out notes and drawing between them. Open one from the squares icon in the rail, or right-click a folder → New canvas here. Drag notes in from the file tree; they show live and open with a double-click.

Tool keys: V select, T text, R box, O ellipse, D diamond, A arrow, P pen. Ctrl+Z undoes. Canvases are saved as JSON Canvas files, the same format Obsidian uses.

Chapter 10

Locked notes

Lock a private note with a password: right-click it → Lock with password…, or a folder → Lock folder with password…. On disk the note becomes unreadable, so it stays private even if the folder is synced or copied. Its file name stays visible.

  • A note stays open until you choose Lock all notes now in the palette, leave Marrow alone for 15 minutes (change it in Settings → Editor), or close Marrow.
  • Locked text is kept out of search, tasks, the graph, backlinks, AI, plugins and published websites.
  • Remove lock… turns it back into plain Markdown.
There is no way to recover a forgotten password. Not by Marrow, not by anyone. Use the hint, and keep the password somewhere safe.
Chapter 11

Publish a website

Turn the vault, or one folder, into a small website: Ctrl+K → Publish as a website…, or right-click a folder. Pick a title and an empty folder, then Publish. You get one page per note with working links, images, diagrams, maths, a sidebar, "Linked from" lists, search and a phone-friendly menu.

What visitors see

Nothing is uploaded. To put the site online, drag the folder onto Cloudflare Pages or Netlify, or push it to GitHub Pages. Locked notes and notes with publish: false are always left out.

Chapter 12

AI, with your own account

Marrow has no AI of its own and sends nothing anywhere until you connect one in Settings → AI. Use your own key for OpenAI, Claude, Gemini, Mistral, DeepSeek, Qwen and many others, or a free model on your own computer with Ollama or LM Studio.

  • Select text in Source and click AI, or press Ctrl+J: improve, shorten, translate, change tone, turn into a table.
  • /ai on an empty line writes at the cursor.
  • Ask my notes (Ctrl+Shift+J) answers from your whole vault and cites the notes it used.
  • Search by meaning finds notes by what they mean, not only their words.

Keys are kept in Windows Credential Manager, never in your notes. Only the text you ask about is sent, and only when you ask.

Chapter 13

CSS snippets and plugins

Settings → Customize. Snippets are .css files that restyle Marrow; they live in the vault's .marrow/snippets folder and travel with it. Plugins add commands to the palette.

Each plugin runs in a sealed sandbox. It can't reach the internet, Marrow's window or your files; it can only ask Marrow through a small API, and only for what you allowed. Locked notes are never shown to plugins.

Chapter 14

Settings and themes

Open Settings with Ctrl+, or the gear in the rail.

  • Spell check underlines misspelt words in Source; right-click one for suggestions. It uses Windows' own dictionaries.
  • Vim keys: normal, insert and visual modes; :w saves.
  • Vault: daily-note folder, templates folder, link format, cloud sync and import.
  • Hotkeys: see and change every shortcut.
Chapter 15

How Marrow keeps your text safe

  • Another app edits the note you're typing in (OneDrive, Dropbox, your phone): Marrow merges both versions. If you both changed the same lines, both are kept.
  • A save fails (file locked, disk full): your text is kept in a backup and offered back next time you open the note.
  • Deleted notes go to .marrow/trash, not straight off the disk.
  • Cloud drives: create a vault inside your OneDrive, Dropbox, Google Drive or iCloud folder, or sync a local vault with one in Settings → Vault → Sync.
