# Welcome to Marrow

Every note is a plain Markdown file in a folder you own. Marrow saves as you type.

## Try these
- [x] Open **Today** and jot something down
- [ ] Link notes by typing `[[`, like [[Garden plan]]
- [ ] Add a #tag, then find it under Tags
- [ ] Ask your notes a question

> [!tip] Sync
> To see these notes on your computer too, set up sync in Settings.
